SOC算法详解

SOC算法理论基础

SOC定义：
SOC (State of Charge) = (当前容量 - 基准容量) / (顶端容量 - 基准容量) × 100%

其中：

  • 当前容量：实际可放出的容量
  • 基准容量：放电截止时的容量（通常为0）
  • 顶端容量：充满电时的容量

SOC算法架构

1. 安时积分法（基础算法）

其中：

  • Q(t)：t时刻的容量
  • I(t)：t时刻的电流
  • Δt：采样周期
  • η：充放电效率（充电<1，放电≈1）
  • Q_total：总容量

2. 温度修正算法

理论基础：
锂电池的可用容量随温度变化：

  • 低温：内阻增大，可用容量下降
  • 高温：内阻减小，可用容量增加

4. 多源融合修正策略

理论基础：
综合安时积分、温度修正、电压修正三种方法，采用加权融合：

融合策略：

  1. 如果温度修正SOC与电压修正SOC误差≤3%：
    融合SOC = (温度修正SOC + 电压修正SOC) / 2

  2. 如果温度修正SOC与当前SOC误差≤3%：
    融合SOC = (温度修正SOC + 当前SOC) / 2

  3. 如果电压修正SOC与当前SOC误差≤3%：
    融合SOC = (电压修正SOC + 当前SOC) / 2

  4. 否则（三者误差都>3%）：
    融合SOC = (温度修正SOC + 电压修正SOC + 当前SOC) / 3

  5. 修正阈值：只有融合SOC与当前SOC误差≥0.5%时才执行修正

5. 总容量自动标定

理论基础：
通过完整的充放电循环，自动标定电池的实际总容量。

标定原理：
充电标定：

  1. 记录低压点（如2.8V）的充电容量 Q_low_chg
  2. 记录高压点（如4.2V）的充电容量 Q_high_chg
  3. 计算净充电容量：
    Q_net = (Q_high_chg - Q_low_chg) × η_chg - (Q_high_dhg - Q_low_dhg)

其中η_chg为充电效率（如0.98）

  1. 温度电流修正：
    Q_actual = Q_net × f(T, I)

  2. 误差校验（与历史值比较，误差>20%则丢弃）

  3. 更新总容量：
    Q_total_new = (Q_actual + Q_total_old) / 2

6. SOC平滑显示算法

理论基础：
为避免SOC跳变影响用户体验，采用分段平滑算法：
- 高SOC区（>95%）：快速响应（5s到达）
- 中SOC区（90-95%）：中速响应（15-30s）
- 低SOC区（<90%）：慢速响应（>30s）

SOH算法详解

SOH算法理论基础

SOH定义：
SOH (State of Health) = 当前最大可用容量 / 额定容量 × 100%

衰减机理：

  1. 循环老化：充放电循环导致活性物质损失
  2. 日历老化：时间导致的自然衰减
  3. 温度老化：高温加速老化
  4. 深度放电老化：DOD越大，衰减越快

1. 容量法计算SOH

理论公式：
SOH_capacity = (实际总容量 / 额定容量) × 100%

其中：

  • 实际总容量：通过自动标定获得
  • 额定容量：出厂标称容量

2. 循环次数法计算SOH

理论基础：
根据电池循环寿命曲线估算SOH：

衰减模型：
SOH_cycle = 100% - (实际循环次数 / 额定循环次数) × 20%

假设：

  • 额定循环次数：2000次（80% EOL）
  • 线性衰减：2000次后衰减到80%

3. 双方法融合策略

融合逻辑：

  1. 如果两种方法误差≤5%：

    • 以循环次数法为准（更稳定，防止跳变）
    • SOH = timSoh

  2. 如果两种方法误差>5%：

    • 取平均值
    • SOH = (capSoh + timSoh) / 2
    • 限制：SOH不能增大
    • 限制：每次最大下降0.5%

4. SOH更新触发条件

触发时机：
1. 充放电循环次数变化时
2. 总容量被修正时

3. 接触器控制策略

理论基础：
根据电流方向选择断开顺序，避免拉弧：

充电状态（电流流入）：
外部 → 主负 → 电池 → 主正 → 外部

断开顺序：先断主负（电流流入端）

放电状态（电流流出）：
电池 → 主正 → 外部 → 主负 → 电池

断开顺序：先断主正（电流流出端）

4. 重复保护机制

理论基础：
防止频繁保护-恢复循环，采用计数机制：

重复保护逻辑：
1. 10分钟内连续3次保护 → 不再自动恢复
2. 保护间隔1小时后 → 允许再次尝试
3. 转为充放电保护 → 防止反复触发

均衡控制算法

1. 均衡控制理论基础

均衡目的：
消除单体电池间的不一致性，提高电池组可用容量和寿命。

不一致性来源：

  1. 制造差异：容量、内阻不一致
  2. 温度差异：散热不均导致老化速度不同
  3. 自放电差异：不同单体自放电率不同

2. 压差积分均衡算法

理论基础：
采用压差积分而非瞬时压差，避免瞬态波动导致的误均衡：

其中：

均衡判据：
